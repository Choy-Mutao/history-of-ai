# 2026-08-16 · Phase 2：交叉验证与候选更新报告

> 承接 `2026-08-16-phase1.md`。本文记录 Phase 2 的实现与验证结果。

## 实现内容

- `src/lib/verify.ts` — 事件聚类与交叉验证：
  - 分词：拉丁字母/数字按词切分，CJK 按二元组（bigram），纯规则实现，零 NLP 依赖；
  - 相似度：Jaccard ≥ 0.45，或包含度 ≥ 0.7 直接判同；
  - 聚类条件：不同信源 + 发布时间相差 ≤48h + 标题相似，并查集合并为「事件簇」；
  - 簇内独立信源 ≥2 → `corroborated: true`。
- `src/scripts/report.ts` — 生成 `src/reports/YYYY-MM-DD.md`：
  - 采集概况表（含信源级错误标注）；
  - 三段结构：已交叉验证 / 高可靠信源（官方智库单信源）/ 待核实；
  - 每个事件附「建议更新位置」（关键词规则：白皮书→书、融资→世家、
    人物→列传、发布开源→本纪/年表），仅供人工参考；
  - 支持指定日期：`npm run collect:report -- 2026-08-16`。
- 新增 npm script：`npm run collect:report`。

## 验证结果（2026-08-16 本地实测）

1. **真实数据**：当日 60 条新增 → 聚为 60 个事件，0 个交叉验证。
   用「跨信源 4 字以上中文公共子串」嗅探复核，当日各信源选题确实无重叠，
   0  corroborated 为真实结果而非算法漏报。
2. **合成数据**：3 个信源报道同一事件（含 ±1 天日期差、标点差异）正确聚为
   一簇并标记 ✅；无关条目保持独立簇。
