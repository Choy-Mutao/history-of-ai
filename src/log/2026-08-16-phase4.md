# 2026-08-16 · Phase 4：信源扩充、AI 过滤与 HTML 采集

> 承接 `2026-08-16-phase3.md`。本文记录 Phase 4 的实现、排障与验证结果。

## 实现内容

### 1. 信源扩充（9 个 enabled，2026-08-16 全部实测）

新增 RSS：IT之家、极客公园、开源中国、钛媒体。
新增 HTML：中国信通院白皮书发布页（首个 `type: 'html'` 启用的信源）。

被否决的路线（实测记录已写入 `sources.ts` 各条 notes）：

- 机器之心：/rss 为 HTML 页；首页 SPA 无静态链接；`/api/v1/articles` 无链接
  无日期且内容陈旧（返回 2022 年文章）——保持 disabled；
- 虎嗅（连接超时）、品玩 /feed（text/html）、cnBeta backend.php（跳转 MSN）、
  智东西（500）、RSSHub 公共实例（国内网络不可达）；
- 上海 AI 实验室：新闻页 JS 驱动（`javascript:void(0)`），不适用 HTML 提取。

### 2. AI 相关性过滤（`lib/filter.ts`）

- 关键词表（中文 + 英文，覆盖术语/模型产品/算力/机构），匹配标题与摘要；
- 泛科技信源在 `Source` 上设 `aiFilter: true`（少数派、IT之家、极客公园、开源中国）；
- 从宽设计：宁可误留不可误杀；过滤数量计入 stats 并在报告概况表展示。

### 3. HTML 列表页采集（`lib/fetch-html.ts`）

- cheerio 按 `selectors` 配置提取（item / titleAttr / date / dateScope / linkPattern）；
- 相对链接用 `new URL(href, base)` 解析；日期支持 `2026-01-14`、`2026/1/5` 等格式；
- 同一 dateScope 内多个同选择器节点时，取第一个含日期的（信通院表格里标题与日期
  同为 `span.kxyj_text`，初版误取标题导致日期回退为当天）。

### 4. 抓取层修复（`lib/fetch.ts`）

- **CDATA 数组 bug**：fast-xml-parser 遇到换行包裹的 CDATA 时把元素解析为数组，
  导致极客公园/开源中国标题为空、条目全被丢弃；`toText` 增加数组递归解包；
- **TLS 指纹拦截**：信通院按 TLS 指纹拦截 Node/undici（浏览器 UA 也 412，系统
  curl 却 200）；`fetchText` 失败时自动回退系统 `curl` 子进程（dev 与 CI 均有）；
- UA 统一为 Chrome 浏览器串。

## 运维备忘

- 指纹变更注意事项：fingerprint 基于 link+title，若信源改 URL 结构会导致旧条目
  重收一次（无害，报告去重看日期）；
- 修正已入库条目时（如本次 caict 日期修复）：从 `state.json` 删对应指纹、
  从当日 raw 删条目后重跑 `npm run collect`。
