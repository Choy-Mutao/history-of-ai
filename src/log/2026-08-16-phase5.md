# 2026-08-16 · Phase 5：报告降噪、docs 桥接与单元测试

## 实现内容

### 1. 报告降噪与排序（`lib/score.ts` + report.ts 重构）

- 启发式重要性评分：交叉验证 +3、多信源每源 +1（封顶 3）、高可靠信源 +2、
  里程碑关键词（发布/开源/白皮书/融资/图灵奖等）+2；
- 报告新结构：**今日要点（Top 10）** 一行一条（标题/验证状态/日期/评分/建议位置），
  审核成本从通读 151 个事件降为扫 10 行；
- 完整事件按评分降序移入附录，评分随条目展示。

### 2. 报告 → docs 桥接（`lib/timeline-check.ts`）

- **已收录检测**：直接 import `docs/.vitepress/data/timeline.ts`，
  按「同年 + token 显著重合（Jaccard≥0.25 或包含度≥0.5）」判定；
  已收录事件沉底到「仅供参考」附录，不再占据审核注意力；
- **timeline.ts 条目草稿**：已交叉验证且未收录的事件自动生成可粘贴的 TS 片段
  （year/month/事件/一手来源链接已填，event_en 与书面语润色留 TODO 人工完成）。

### 3. 单元测试（`src/tests/`，node:test + tsx，零新依赖）

18 个用例全部通过：

- `verify.test.ts`：分词、跨信源聚类、±1 天窗口、同信源不聚类、超窗不聚类；
- `filter-dedupe.test.ts`：AI 过滤正负例、指纹稳定性、增量去重；
- `fetch-timeline.test.ts`：`toText` 各形态（含 CDATA 数组回归用例）、
  `isRecorded` 注入式测试（不依赖真实 timeline.ts）；
- `npm test` 加入 collect.yml CI（采集前先跑测试）。
