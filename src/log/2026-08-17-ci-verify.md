## skipInCI 机制

CI 运行时发现：信通院（caict）从 GitHub 境外机房 IP 访问被 WAF 拦截（HTTP 412，
curl 兜底同样无效）——该站封锁数据中心 IP，本地（国内 IP + 浏览器 TLS 指纹）正常。

处置（本次提交）：

- `Source` 新增 `skipInCI?: boolean` 字段，caict 标记为 true；
- `collect.ts` 在 `process.env.CI` 为真时跳过此类信源；
- 结论：caict 仅本地采集，CI 日报不再出现该项报错；其余 8 个信源 CI 全部正常。
